## 二、码里写的是什么

12 张码内容各不相同，格式统一是：

```
https://lab-ar-nav.app.workbuddy.host/fp-ar.html?sharecode=COAQ2BOKWL&loc=P-B2-01
                                                                       ↑ 只有这一段不同
```

`loc=` 这一段就是「我在哪个楼梯口」。页面读到它就直接定位，不用再选楼层。

## 四、印之前必须交代打印店的三句话

1. **「按实际大小印，选 100%，不要选『适应页面』」** —— 一缩码就小，模块宽度掉下去就扫不出。
2. **「哑光覆膜，不要亮膜」** —— 亮膜一反光，摄像头里就是一片白。
3. **「二维码四周那圈白边不能裁」** —— 那 4 模块静区是码的一部分，裁掉就废。

印完拿尺量一下：**码的黑框外沿到外沿应该是 127mm 左右**（含白边整块 150mm）。差太多就是被缩放了，整批重印。

## 五、贴哪里

| 项 | 要求 |
|---|---|
| 码中心高度 | **1.45 米**（范围 1.40–1.65m，对齐举手机的高度） |
| 墙面朝向 | 与通行方向**垂直**，视夹角 ≤30° |
| 每处几张 | **2 张**（1.45m 主位 + 1.65m 备位），高矮个子都能扫 |
| 上下楼错开 | 同一位置上下层的牌错开 **20cm**，避免同框误读 |
| 材料 | PVC 背胶 或 亚克力 UV 打印；纸质的 3 个月就卷边发黄 |

**绝对不要贴**：门背后、门扇上、消防栓箱门盖、开关面板上、强反光瓷砖对面、阳光直射的墙、窗户正对面（逆光）、洗手间外墙（潮气）、低于 1.2m 的地方。

## 八、这套码的唯一风险

**`sharecode=COAQ2BOKWL` 是托管平台的访问凭证，平台重新发布应用时它会变。一旦变了，墙上这 12 张全部失效、必须重印。**

要根治，只有一条路：**落实自有短域名 + 跳转层**。

`deploy/redirect/index.html` 已经写好了（路径末段 `p-b2-01` → `P-B2-01` → 拼 sharecode 跳转），sharecode 只在那一个常量里。域名到位后：

1. 把 `deploy/redirect/index.html` 部署到你的域名根目录，404 兜底也指向它
2. 一条命令重出码：
   ```bat
   python tools\make_qr.py --short-base https://你的域名 --out qr_final_short
   ```
3. 那批码内容是 `https://你的域名/p-b2-01`，短得多、模块更大更好扫，而且**以后换 sharecode 不用重印**

在域名落实之前，这 12 张就是能用的最终版 —— 平台只要不重新发布，它们一直有效。
