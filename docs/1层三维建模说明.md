## 一、为什么 1F 必须单独做

用户明确要求：**1 层结构布局与 2、3、4 层并不相同，不得沿用**。实测确认这个判断是对的：

| | 2/3/4 层 | **1 层** |
|---|---|---|
| 平面形态 | 整层"回"字形环廊 + 中央天井 | 天井更大，**四周走廊不闭合成环** |
| 南侧 | 一排小实验室（301~310） | **101 一间大空间**（四间实验室合并：土木材料-1 / 土力学 / 工程结构-1 / 力学基础-1） |
| 西侧 | 314/313/312 三间竖排 | **107 一条南北狭长房间**（土木材料-3） |
| 北侧 | 8 间小房间 | **108/109 两间大房**，中间夹一条南北走廊 |
| 东翼 | 332~335 + 333 套间 | **错层**：115 大房 + 东楼梯 + 118/119/121 三小间（上排），116/117/120（下排） |
| 房间数 | 47 / 46 / 46 | **32** |

所以 1F 是**从零实测**的，没有复制任何其他层的矩形。

## 二、量图流程（这套流程可复用到 4F）

问题：这张疏散板照片**光照严重不均**（左侧偏暗、右上有反光），直接做红掩膜，
左侧的墙线覆盖率只有 0%，右侧有 90% —— 墙会整片消失。

### 四步流水线

```
① 平场校正  nav3d/tools/flatten_1f.py
   用大窗口(151px)估计背景亮度，逐像素除以背景 → 消除明暗差
   效果：左侧暗区红覆盖率 0% → 6.9%，与中部 6.2% 持平

② 去倾斜    nav3d/tools/deskew_1f.py
   扫描件有 -0.95° 旋转，不校正同一面墙的 y 会漂移 10+ px
   做法：试一系列角度，取"行/列投影直方图平方和最大"的角度

③ 墙线定位  nav3d/tools/locate_1f.py
   不用全图投影（会被房间号大字干扰），改用"条带内覆盖率 + 最长连续段"
   判据：某行/列在指定条带内覆盖率 ≥55% 且最长连续段 ≥40px 才算墙

④ 肉眼核对  nav3d/tools/plan_check_1f.py
   把矩形画回原始板子上，逐间看是否贴墙
   ⚠ 这一步不能省：自动量出来的坐标必然有偏差，靠肉眼修
```

### 实测到的墙坐标（去倾斜图坐标系，1773×2364）

```
横墙 y：295(北外墙) 597 605 656 705 828 933 1058 1117 1174 1306 1409 1468 1551 1600 1747(南外墙)
竖墙 x：158 182 268 322 342 375 491 549 561 734 1101 1153 1242 1400 1470 1651(东外墙)
```

## 六、已知的不足（如实记录）

1. **门宽是估的**：1F 板实测 23 px/m，0.65m 的门只有 15px，属于"勉强"档
   （见 `docs/疏散图板补拍规格.md`）。所以 `doorW` 字段精度约 ±15cm。
2. **`pxPerMeter` 是折算的**：不是直接量出来的，而是用"1F 板外轮廓跨度 ÷ 3F 外轮廓跨度"折算。
   若以后有实测尺寸（比如量一间房净宽），应当回来校正。
3. **走廊宽度是推的**：`COR-N`（北侧）等几段走廊的边界，板子上墙线断开处较多，
   按相邻房间边界对齐补的，可能与实际净宽有几十厘米出入。
4. **没有窗户数据**：1F 疏散板上不画窗，只有 108/109 用 `winSides` 猜了北墙大窗。
   其余外墙房间目前是实墙，需要走廊实拍才能补（见 `docs/走廊拍照清单.md`）。
5. **楼梯踏步数是估的**（8/7/7/7 级），需现场拍楼梯间内部。
