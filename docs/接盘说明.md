## 2. 项目是什么（一句话）

**不用装 App、没有后端**的室内导航：走廊贴二维码 → 手机扫码 → 页面知道"你在哪个楼梯口" →
选目的地 → 出路线、分步文字指引、AR 箭头，外加一个可交互的三维沙盘。
现在装的是**第二实验楼 2 / 3 / 5 层**的真实数据。
**1 层与 4 层尚未建模**，但疏散板照片已就位（`_boards/f1.jpg`、`f1_all.png`、`f4.jpg`），随时可开工。

技术栈：**纯前端原生 JS**，ES5 风格（IIFE + `'use strict'` + `var` + `window.X` 全局 + 中文块注释），
无框架、无打包器。三维用 three.js r128（离线内置）。数据是"JSON 穿 JS 马甲"，走 `<script src>` 加载，
所以 `file://` 也能开（但手机扫码必须 `http://`）。


`https://<你的域名>/p-b2-01`（更短、模块更大更好扫，且换 sharecode 不用重印）：

```bat

```

`qr_pilot/`（3 张临时版）与 `qr_pilot_short/`（域名占位符，扫不通）都是早期的试点样例，

## 5. 已确认的决策与硬规则（别推翻，推翻前先问）

1. **键位**：W 前 / S 后（只位移不转向）；**A/D = 左转/右转视角**；←→ 也是转身；Shift+←→ 平移。
   A/D 曾被改成平移，用户明确要求改回转向 —— 不要再翻。
2. **墙清理**：只删房间矩形深处的墙 + 路网两侧 12px 内的走廊假墙。
   曾试过更激进的"edge-band"版本，把承重墙也删了，被否掉。
3. **派生楼层不能整段抄"楼体核心"**：2/3/5 层的楼梯、厕所在哪一排、门朝哪**可能完全不同**。
   5 层最初直接 `dict()` 抄 3 层的楼梯/厕所，导致楼梯占了厕所位置、501 跟东楼梯上下互换。
   **必须逐层按各自板子重画。**
4. **"兜底换面"是寻路的万恶之源**：宁可报"不通"，也不许偷偷换一条不该存在的路。
5. **楼板必须显式定义**（只挖 corridors + spurs），不许"默认全图可走" —— 大图上必然穿墙。
6. **用户说"拆墙"时只拆他点名的那一处**；他看图说"补上"就是全撤、回到"每间房只留一个门"。
7. **5 个楼梯口都是定位起点**，各配一个二维码（P-B2-01~05 三层、06~07 五层、08~12 二层）。
8. **数据共享、页面隔离**：`data/labs.js` 改动所有对话框同步；但各个 html 页面归各自的线负责
   （本线负责 `fp-ar.html` + `nav3d/index.html`，`fp.html` 不是本线的页面）。

## 8. 三维沙盘的验证方式（改完必须走这条）

```bat
:: 1. 路网连通性（连通块必须 = 1）
cd nav3d && python tools/check_grid.py 3F && python tools/check_grid.py 2F && python tools/check_grid.py 5F && cd ..

:: 2. 重新打包
python nav3d/tools/build_single.py

:: 3. 浏览器自检 + 截图（看 data-bad 必须是空字符串）
node nav3d/tools/shot_nav3d.js B2-3 nav3d/shot-3d-3f.png "noauto=1&selftest=1"
node nav3d/tools/shot_nav3d.js B2-2 nav3d/shot-3d-2f.png "noauto=1&selftest=1"
node nav3d/tools/shot_nav3d.js B2-5 nav3d/shot-3d-5f.png "noauto=1&selftest=1"
```

`selftest` 会对每间房试走一遍；套间（334/335 via 333、234/235 via 233）还要额外满足：
① 宿主可达 ② 门开在与宿主共用的那道墙上且落在宿主跨度内 ③ 自己那道门不许直通公共走廊。

排查单间用 `?probe=<房间ID>`，输出该房间每个面的门点是否可走、是否可达、以及最终路线点。

## 9. 如果你只想知道"现在能不能用"

**能。** 六步验收全绿（第 6 节）。本地 `start-server.bat` 起服务后用手机连同一 WiFi 即可试；
手机上真机用摄像头**必须 https**（浏览器安全上下文限制），本机 `localhost` 不受限。

唯一没闭环的是"印出去贴墙上的二维码"——卡在短域名（第 7 节 P0）。
